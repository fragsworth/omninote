    About this notepad

    One HTML file, no dependencies, no server, no account. Every note is stored in this browser's local storage on this device, and nothing is ever sent anywhere.

    Because the notes live in the browser, clearing site data removes them. Use File → Back up all notes to keep a copy you own, and File → Restore backup to bring it back or move it to another browser.
