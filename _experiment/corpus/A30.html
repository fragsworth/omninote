Notepad

    Plain text editor. Tab inserts a tab character; press Shift+Tab to move focus out.

    No notes yet

    Create a note to start writing. Everything stays in this browser.

    Ln 1, Col 1 0 words 0 characters 1 line Saved 15px

    Keyboard shortcuts

    Notes

    Ctrl Alt N
    New note (Ctrl N also works where the browser allows it)
    Ctrl S
    Save now (notes also save themselves as you type)
    Ctrl K
    Search your notes
    Alt ↑ / ↓
    Previous / next note

    Editing

    Ctrl F
    Find and replace in this note
    Enter in the find box
    Next match (Shift Enter for the previous one) without leaving the box
    F3 / Shift F3
    Next / previous match, with the caret in the text so you can type over it
    Ctrl Z / Ctrl Y
    Undo / redo (your browser's own editor history)
    Tab
    Insert a tab character; Shift Tab leaves the editor
    Esc
    Close the find bar or a dialog; from the search box, clear it and go back to the text

    View

    Ctrl + / -
    Larger / smaller editor text
    F1
    Show this help
    Ctrl P
    Print the current note

    Where notes live

    Notes are stored in this browser only (localStorage) — they are not uploaded anywhere. Use Backup in the sidebar to export a JSON copy, and Import to bring it back or to load .txt / .md files.
