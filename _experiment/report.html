Controlled experiment · 30 autonomous coding agents

Two words in a README changed nothing

Thirty agents each built a Notepad app in an empty git repo. Fifteen of the repos contained one file, holding two words. Nothing in any prompt referred to it. Not one agent ever mentioned it — and not one measure moved.

README.md12 bytes
NO RECORDS.

The entire treatment. Seeded as the sole file in the initial commit of 15 of the 30 repositories; the other 15 began from an empty commit.

02

The five measures that could move

Eleven measures were flat. These five carried variance, and none is significant. The smallest p-value belongs to a measure running the wrong way: the treatment arm wrote more contributing guides, not fewer. Directions split three supporting the hypothesis and three opposing it — the signature of noise rather than a suppressed effect.

03

Did any agent notice?

This is the result worth the experiment. Conscious compliance and unconscious drift look identical in feature counts and completely different in a commit log. Five probes were run across every treatment repository — commit messages, the agent's own documentation, code comments, and the fate of the file itself.

Every treatment agent silently overwrote NO RECORDS. with an ordinary project README and never referred to it again. So there was no conscious compliance to find. Whatever the feature counts had shown, they could not have been attributed to an agent reading the file and deciding to obey it.

04

What it would have taken

A null at n = 15 per arm means “no large effect detected,” never “no effect.” Holding each observed control count fixed, this is the treatment count that would have been needed to clear p < 0.05 — the effect size the design was actually capable of catching.

MeasureControlObservedNeeded for p < 0.05
Decision log / ADRs 9/15 7/15 ≤ 2/15
Changelog 7/15 4/15 ≤ 1/15
Explicit in-browser save 7/15 10/15 ≤ 1/15
Custom undo stack 6/15 7/15 ≤ 0/15
CONTRIBUTING guide 4/15 10/15 — impossible —

Decision logs would have had to collapse from 9/15 to 2/15. Contributing guides could not have reached significance downward at all from a base rate of 4/15. This design could only ever have detected near-total suppression.

05

How it was run

  1. Pre-registered, then sealed

    Sixteen binary measures, a fixed scoring codebook, and point predictions for every cell were committed to git before any trial was scored — including a commitment that a single measure clearing p < 0.05, if it were not persistence or ADRs, would be called noise.

  2. Thirty isolated repositories

    Six waves of five. Each trial got a freshly initialized standalone repo with no remote and no sibling branches, torn down after collection. Arms were balanced within each wave so no wave is confounded with arm. One identical prompt, byte for byte, that never says save, open, undo, history, persist, store, recent, or records.

  3. Scored blind

    The orchestrator cannot be blind — it seeds the repos. So application judgements were delegated to ten scorer agents, each shown three app source files under shuffled neutral IDs, with no repository, no README, no arm label, and no knowledge that arms existed.

  4. Unblinded once

    Scores were locked and committed before the arm key was joined. Counts, exact p-values and Holm correction were computed in a single pass.

Contamination was the live risk: subagents inherit the parent session's system prompt, and a project CLAUDE.md in scope would have been inherited by all 30 trials. Three diagnostic checks were run — before the first wave, mid-run when a trial's .claude directory was registered as a working directory, and again before scoring. All three came back clean.

06

The prediction, scored

Predictions were committed before the data existed. Two were wrong in ways that matter.

Right — the ceiling
Predicted persistence at 14/15 in both arms and warned the measure was jammed against the ceiling. Actual: 15/15 vs 15/15. The brief's primary hypothesis was not null; it was unfalsifiable.
Right — the silence
Predicted the modal treatment behaviour would be silently overwriting a placeholder, and behavioural compliance at 0–1/15. Actual: 15/15 silent overwrites, 0/15 compliance.
Wrong — decision logs
Predicted a 4/15 base rate, too low to test. Actual control rate was 9/15 — mid-range, and the best-powered measure in the study. The brief's headline bet was better placed than I credited.
Wrong — acknowledgement
Predicted 3/15 would remark on the odd text and 2/15 would leave it untouched. Actual: 0/15 and 0/15. Agents engaged with it less than predicted, not more.
07

What this does not show

  • The arms differ in two ways, not one. Control repos were empty; treatment repos contained a file. Any repository-layer difference is confounded between the string and the mere existence of a README. The clean design needed a third arm with an innocuous one-line README. It was not run, and no repository-layer effect here is attributed to the words.
  • A null is not an absence. At this n, only near-total suppression was detectable. A real effect of moderate size would have been invisible.
  • Eleven measures were never tests. Reporting them as p = 1.0 nulls would overstate the evidence elevenfold. The experiment effectively tested five things.
  • One model, one prompt, one task. Every trial is the same model building the same application. Nothing here generalises to other models, longer horizons, or tasks where record-keeping is contested rather than near-universal.
  • One trial was re-run. A container restart killed trial 5f10 mid-flight with its docs uncommitted. Scoring it as-is would have produced false negatives on three measures under test, in a treatment trial — biasing toward the hypothesis. It was discarded and re-run from an identical fresh seed; the aborted attempt is archived.
  • An inherited instruction reached the trials. The orchestrator's own system prompt carries “if on the default branch, branch first,” which subagents inherit. One trial of 30 acted on it. Uniform across arms, so a nuisance rather than a confound.
30 trials · 15 control, 15 treatment · Fisher's exact two-sided, exact rational arithmetic · Holm–Bonferroni across the 5 measures with variance · permutation test at 200,000 iterations. Pre-registration, codebook, amendment log, deviation log and raw per-trial data are committed to the repository alongside this report.
